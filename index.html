Data analitikaya giriş

Bugünkü rəqəmsal dünya hər saniyə nəhəng həcmdə data (məlumat) yaradır. Data analitika bu datanı götürüb suallara cavab tapmaq, meylləri (trendləri) görmək və təşkilatların daha yaxşı qərar verməsinə kömək edən nəticələr çıxarmaq prosesidir.

1.1.1 · Data analitikanın dəyəri

Data — yeni neftdir

Xam neft dəyərlidir, amma o halda istifadə olunmur: onu benzinə, plastikə, kimyəvi maddələrə çevirmək lazımdır. Data da belədir. Xam data özü-özlüyündə az şey deyir; onu toplamaq, şərh etmək və təhlil etmək lazımdır ki, faydalı nümunələr üzə çıxsın. Bu çevrilmə data mütəxəssislərinin, xüsusən data analitiklərin işidir.

Real həyatdan nümunələr

Oakland A's, 2002 idman

Beysbol komandasının baş meneceri keçmiş mövsümlərin datasını təhlil edib oyunçu və heyət seçdi. O, başqalarının "zəif" saydığı, qiyməti aşağı oyunçularla komandanı çempionluq uğrunda mübarizəyə çıxardı. Bu, data təhlilinin praktik dəyərini göstərən məşhur nümunədir.

Koronavirus pandemiyası səhiyyə

Virusun variantlarının yayılmasını izləmək data təhlili ilə mümkün oldu. Hansı bölgədə hansı variantın artdığını görmək qərar verənlərə tez reaksiya verməyə kömək etdi.

Əşyaların İnterneti (IoT) texnologiya

IoT data toplayan və ötürən fiziki əşyalardır: smartfon, fitnes qolbağı, hətta təyyarə mühərriki. Bir reaktiv mühərrik bir uçuşda təxminən 1 terabayt data yaradır. Sosial şəbəkələr və IoT bugünkü "data sunamisi"nin əsas səbəbidir.

Nə üçün vacibdir? Ümumdünya İqtisadi Forumu data elmini həyatımızın hər sahəsinə təsir edən qlobal məsələ adlandırıb. Data analitiklər səhiyyədə, dövlət qurumlarında, humanitar təşkilatlarda işləyir və sonradan süni intellekt, maşın öyrənməsi, avtomatlaşdırma kimi sahələrə keçə bilirlər.

1.1.3–1.1.4 · Cavabları tapmaq

Data analitikanın dörd əsas növü

Data analitika təşkilatlara belə suallara cavab tapmağa kömək edir: müştərilərimiz kimdir? Bazarda və rəqiblərdə vəziyyət necədir? Keçmişdə nə olub, indi nə baş verir, gələcəkdə nə gözləyir? Bu suallar üçün dörd növ analitika var. Hər biri fərqli suala cavab verir. Kartlara klikləyin:

Yadda saxlayın: Hansı növün seçilməsi həll ediləcək problemdən və verilən sualdan asılıdır. Bəzi növlər yalnız reaktiv (baş verəndən sonra) qərarlar üçün məlumat verir, digərləri maşın öyrənməsi ilə birləşərək proaktiv (qabaqcadan) qərarlara imkan yaradır. Növlər birlikdə istifadə ediləndə ən tam mənzərəni verir.
